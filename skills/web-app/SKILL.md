# Веб-приложение с публичной ссылкой

Применяй, когда владелец просит «сделай веб-приложение», «опубликуй страницу», «дай ссылку,
которую откроет кто угодно» — или просит показать/удалить уже опубликованные.

Приложение — FastAPI + статика, работает на твоей машине отдельным процессом в своём systemd-юните
(свой uid, свой каталог данных, без доступа к твоим файлам). Ссылку открывает любой: право — знание
секрета в URL, не Telegram-аккаунт.

## Как действовать

### Создать

```bash
~/.hermes/skills/web-app/scripts/new-app <имя>
```

Имя — строчные латиница, цифры и дефис, до 32 знаков. Скрипт сам: зарегистрирует приложение у
бота (выбор порта и ссылки), соберёт Python-окружение, создаст systemd-юнит, запустит и проверит
здоровье. **Ссылка печатается в конце — только после успешной проверки**; отдай её владельцу.

- Лимит приложений задаёт бот (обычно 5); при превышении скрипт скажет и предложит удалить старое.
- Не выдумывай ссылку, если скрипт не напечатал её: приложение не работает.

### Показать

```bash
~/.hermes/skills/web-app/scripts/list-apps
```

Печатает имя, статус и ссылку каждого приложения. Используй, когда владелец спрашивает
«что опубликовано» или потерял ссылку.

### Удалить

```bash
~/.hermes/skills/web-app/scripts/remove-app <имя>
```

Останавливает приложение, убирает юнит и каталоги, освобождает порт. Ссылка перестаёт
открываться сразу. Владелец может удалить и сам — кнопкой в карточке агента.

## Код приложения

Шаблон лежит в `template/`: `main.py` (FastAPI), `static/index.html`, `requirements.txt`
(версии зафиксированы). Меняй код под задачу владельца — при следующем `new-app` с тем же именем
бот вернёт существующую запись и ссылку прежней не изменит.

Путь в браузере начинается с `/app/<id>/`: FastAPI уже настроен на это через `--root-path`,
твои пути внутри приложения работают как в корне. Относительные ссылки строй от корня.

## Чего не делать

- Не пытайся запустить процесс от своего пользователя: правило «не запускай веб-процесс от
  agent». systemd-юниты с DynamicUser — единственный путь, и скрипт делает это сам.
- Не правь содержимое `/etc/agent-apps/`: это ключ регистрации и маркер машины, управляет ими бот.
- Не выдавай ссылку до успешной health-проверки: «ссылка есть, но не открывается» хуже отказа.
